# Challenger Computers - E-Commerce Showcase

A highly customized, interactive e-commerce homepage designed for **Challenger Computers** (a premium custom PC brand based in Chennai, India).

## 🚀 Key Features
* **Bento Grid Category Router**: Asymmetric product category grids featuring interactive highlight cards and custom specs checklists.
* **Compact Specs Dashboard Grid**: High-impact gaming rig listings with hardware spec dashboards and compact, zero-waste visual structures.
* **Interactive Hover Benchmarks**: Hovering over custom rig images slide-up dynamic telemetry overlays indicating live gaming frame rates.
* **3D Morphing Scrolling PC**: An absolute-positioned, hardware-accelerated 3D PC element that floats, spins, and morphs its chassis style across different page sections.
* **Tactile Cabinet Power Switch**: A floating dark-mode toggle designed after gaming cabinet start switches with adaptive amber/red glowing LED indicators.
* **Parallax Blueprint Schematics**: Non-intrusive vector circuit diagrams rotating slowly in background layers to reinforce a technical cyberpunk aesthetic.

## 🛠️ Tech Stack
* **Markup & Structure**: HTML5 (semantic layout)
* **Styling & Frameworks**: Tailwind CSS, FontAwesome Icons
* **Interactions & Telemetry**: Native JavaScript (ES6+, IntersectionObserver, 3D CSS perspective transforms)
* **Typography**: Google Fonts Outfit & Inter
